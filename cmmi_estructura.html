Cómo leer esta tabla: La jerarquía es estrictamente inclusiva — una Categoría (CCA) contiene Áreas de Capacidad (CA), cada CA contiene Áreas de Práctica (PA), y dentro de cada PA las prácticas se agrupan en Niveles de Grupo de Práctica (PG Level 1 a 5). El nivel de madurez mínimo indica a partir de qué ML la PA aparece en el perfil predefinido de appraisal — no que no pueda implementarse antes. Las PAs marcadas CORE son obligatorias para cualquier organización independientemente del dominio; las DOMINIO aplican según el tipo de trabajo (desarrollo, servicios, seguridad, etc.). Las tres filas con NUEVO V3 fueron incorporadas en la release de abril 2023.
